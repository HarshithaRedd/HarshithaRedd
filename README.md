## 👩‍💻 About Me


I’m a **Senior Data Analyst with 5+ years of experience** turning operational, financial, customer, and asset data into decisions teams can act on.

I build KPI frameworks, executive dashboards, forecasting models, and automated reporting workflows using **SQL, Python, Power BI, Microsoft Fabric, and cloud data platforms**. I particularly enjoy taking a process that depends on disconnected spreadsheets, PDFs, or manual updates and rebuilding it as a reliable analytical system.

I use AI where it creates practical value—not simply to add “AI” to a project. That includes extracting structured information from documents, generating management-ready summaries, detecting unusual patterns, and building analytics tools that reduce repetitive work while keeping the underlying logic transparent.

> **A sentence I enjoy hearing:** “We still do this manually every week.”

`Messy data → trusted metrics → automated insights → better decisions`

### 🚛 Fleet Maintenance Analytics Dashboard

An automated analytics application for monitoring vehicle availability, repair activity, maintenance costs, labor hours, and weekly work-order performance.

**What it demonstrates:**

* Extracting structured information from operational PDF reports
* Python-based data cleaning, validation, and transformation
* FastAPI backend serving dashboard-ready data
* Streamlit and Plotly frontend for interactive reporting
* Separate operational views for garbage and recycling fleets
* Automated weekly reporting and management-ready metrics

`Python` `FastAPI` `Streamlit` `Plotly` `pandas` `PDF Automation`

### 📊 Asset Replacement Decision Model

A data-driven workflow for comparing maintenance costs, asset age, repair frequency, and historical performance across more than 150 fleet vehicles.

**What it demonstrates:**

* Asset-level cost modeling
* Keep-versus-replace scoring
* Fiscal-year trend analysis
* Repair categorization
* Forecasting future maintenance expenditure
* Translating analytical results into procurement insights

`Python` `Excel` `Forecasting` `Asset Analytics` `Decision Modeling`
