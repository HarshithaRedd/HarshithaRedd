## Where data meets decision

The most useful analytics work rarely starts with a perfectly prepared dataset.

It usually starts with a question from leadership, two reports that do not agree, a spreadsheet someone updates every Monday, or important information spread across systems that were never designed to work together.

That is the part of the work I enjoy.

I bring those pieces together, work out what can be trusted, and turn them into dashboards, forecasts, analytical models, and automated workflows that help management make informed decisions.

My work sits at the intersection of **data and decision-making**. I care about the technical side—SQL, Python, data modeling, APIs, automation—but I care just as much about whether the final result is clear, useful, and connected to a real action.

I use AI the same way: not as decoration, but as another practical tool for organizing unstructured information, reducing repetitive work, explaining results, and helping people reach useful answers faster.

> **My goal is to turn scattered information into clear direction.**

## How I approach an analytics problem

I usually start with the decision—not the dashboard.

```python
def solve_business_problem(question, sources):
    data = collect(sources)
    trusted_data = validate(data)

    metrics = define_metrics(
        data=trusted_data,
        based_on=question,
    )

    insights = analyze(metrics)
    recommendation = connect_to_decision(insights)

    if the_work_is_repetitive(question):
        automate_the_workflow()

    return recommendation
```

A strong analytical solution should answer four questions:

1. Can the data be trusted?
2. What changed?
3. Why does it matter?
4. What should happen next?
